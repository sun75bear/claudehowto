# 9. FAQ・トラブル対応

困ったときの対処をまとめています。上から順に、よくあるものです。

## 契約・アカウント

??? question "確認メールが届かない"
    迷惑メールフォルダを確認してください。数分待っても届かない場合は、サインアップ画面から再送できます。会社のメールアドレスで届かない場合、社内のフィルタで止まっていることがあるので、個人のアドレスで試すのも手です。

??? question "「上限に達しました」と表示された"
    一定時間あたりに使える量の上限です。数時間待てばまた使えるようになります。頻繁に当たるようなら [Pro プラン](02-signup.md) を検討してください。

??? question "クレジットカードが通らない"
    海外決済が制限されている可能性があります。カード会社に確認するか、別のカードで試してください。

??? question "解約したのに使えるままだが、請求は止まっているか"
    支払い済みの期間が終わるまでは Pro のまま使えます。期間終了後に自動的に無料プランへ戻り、それ以降の請求は発生しません。Settings → Billing で次回請求日を確認できます。

## 使い方

??? question "日本語がおかしい、翻訳調になる"
    「自然な日本語のビジネス文書として書き直してください」と頼めば直ります。最初の指示に「日本語で、自然な言い回しで」と入れておくと起きにくくなります。

??? question "答えが一般論ばかりで役に立たない"
    材料が足りていません。資料を添付するか、前提条件（誰向け・何のため・どんな状況か）を具体的に書いてください。詳しくは [5章](05-tips.md)。

??? question "途中から話が噛み合わなくなった"
    会話が長くなりすぎたサインです。**新しい会話**を開き、必要な材料だけを貼り直してください。

??? question "書いていないことを勝手に付け足される"
    「渡した情報にないことは書かないでください」と明示してください。要約や議事録では特に有効です。

??? question "答えが本当か不安"
    そのまま次のように聞いてください。

    ```text
    今の回答のうち、事実確認が必要な箇所と、あなたの推測が入っている箇所を分けて教えてください。
    ```

    数字・制度・固有名詞は、必ず公式情報で確認してください。

??? question "前の会話の内容を覚えていてほしい"
    同じ会話の中では覚えています。別の会話には引き継がれません。同じ資料を何度も使うなら [プロジェクト機能](03-basics.md) を使ってください。

## Claude Code

??? question "`claude` は認識されません / command not found と出る"
    1. ターミナル（PowerShell）を**いったん閉じて開き直す**
    2. それでも直らなければ `claude doctor` を実行して診断結果を見る
    3. インストールし直す

    詳しくは [公式のトラブルシュート](https://code.claude.com/docs/en/troubleshoot-install)。

??? question "Claude Code が使えないと言われる"
    無料プランでは使えません。[Pro プラン](02-signup.md) になっているか確認してください。

??? question "ターミナルが苦手で進められない"
    [デスクトップアプリ版](https://claude.com/download) を使ってください。ターミナルなしで同じことができます。

??? question "意図しないファイルを書き換えられた"
    許可ダイアログで「今後も許可」を選んでいると起きやすくなります。慣れるまでは「1回だけ」を選び、内容を読んでから承認してください。大事なファイルは事前にコピーを取っておくことをおすすめします。

??? question "毎回同じ説明をするのが面倒"
    作業フォルダに `CLAUDE.md` を置いてください。[8章](08-claude-code-practice.md) で解説しています。

## それでも解決しないとき

- Claude 自身に聞くのが案外早道です。エラーメッセージをそのまま貼り付けて「これはどういう意味で、どうすればいいですか」と聞いてください
- 公式のヘルプセンター: [support.claude.com](https://support.claude.com)
