# 1. Claude とは何か

!!! abstract "このページでできるようになること"
    Claude が何をしてくれる道具なのか、そして**何が苦手なのか**を先に押さえます。ここを飛ばすと「使ってみたけど微妙だった」で終わりがちです。

## ひとことで言うと

**文章で指示すると、文章で返してくれる相手**です。Anthropic というアメリカの会社が作っています。

ただし「賢い検索エンジン」ではありません。検索が**探してくる**のに対し、Claude は**その場で考えて作る**のが得意です。この違いが使い分けの軸になります。

| | 検索エンジン | Claude |
|---|---|---|
| 得意なこと | 既にある情報を探す | 材料を渡して加工・作成する |
| 出てくるもの | ページの一覧 | 目的に沿った答えそのもの |
| 向いている依頼 | 「〇〇の公式サイトはどこ」 | 「この議事録を3行にまとめて」 |

## 得意なこと

実際に頼んで結果が出やすいのは、次のようなものです。

- **まとめる** — 長い資料、議事録、メールのやりとりを要約する
- **形を変える** — 箇条書きを文章に、文章を表に、日本語を英語に
- **たたき台を作る** — 企画書、案内文、お詫びメールの下書き
- **整える** — 誤字脱字、言い回し、敬語のチェック
- **考えを引き出す** — 「この案の穴はどこか」「他の切り口はあるか」
- **調べて説明する** — 知らない分野を、自分のレベルに合わせて解説してもらう

共通しているのは、**材料か目的をこちらが渡している**という点です。丸投げより、材料つきの依頼のほうがはるかに良い結果になります。

## 苦手なこと・できないこと

ここを知らないと事故ります。

**もっともらしく間違えることがある**

Claude は「知らない」と言わずに、それらしい答えを作ってしまうことがあります。統計の数字、法律の条文、人名や日付など、**間違っていたら困る情報は必ず裏を取ってください。** これは Claude に限らず、この種の AI 全般の性質です。

**最新の出来事には弱い**

学習した時点までの知識で答えます。Web 検索の機能を使えば最近の情報も調べられますが、既定では手元の知識で答えることがあります。

**あなたの会社の事情は知らない**

社内ルール、取引先の名前、過去の経緯は当然知りません。必要なら**こちらから資料を貼って渡す**必要があります（[実例集](04-examples.md)でやり方を扱います）。

**計算は苦手なことがある**

桁の多い計算や複雑な集計は間違えます。表計算ソフトの仕事は表計算ソフトに任せてください。

## 他の AI サービスとの関係

ChatGPT、Gemini などと同じ「対話型 AI」の一つです。できることは大きく重なっていて、どれか一つを覚えれば他も使えます。このサイトは Claude を扱いますが、ここで身につくコツは他のサービスでもほぼそのまま通用します。

## まとめ

- 探す道具ではなく、**作る・整える道具**
- 材料を渡すほど良い答えが返る
- 間違えることがある前提で、重要な情報は確認する
