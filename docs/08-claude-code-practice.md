# 8. Claude Code 実践

!!! abstract "このページでできるようになること"
    最初の1時間で何をすればよいかが分かります。安全に使うための勘所も押さえます。

## いちばん大事な習慣：作業用のフォルダを分ける

Claude Code は、**起動したフォルダとその中身**を作業対象にします。

いきなり大事なフォルダで始めず、**練習用のフォルダを1つ作って**そこで試してください。

```powershell
mkdir C:\work\claude-test
cd C:\work\claude-test
claude
```

!!! warning "バックアップを取ってから"
    ファイルを直接書き換える道具です。大切なファイルを扱う前に、コピーを取っておくか、Git などでバージョン管理された状態で使ってください。

## 最初の3つの指示

起動したら、まずこの3つを順に試すと感覚がつかめます。

**1. 状況を把握させる**

```text
このフォルダに何があるか調べて、内容を一覧で教えてください。
```

**2. 読ませて考えさせる（まだ書き換えない）**

```text
このフォルダのテキストファイルを全部読んで、共通するテーマを3つ挙げてください。
まだファイルは変更しないでください。
```

**3. 変更させる**

```text
それぞれのファイルの先頭に、内容を1行で表す見出しを追加してください。
```

3 のときに**許可を求めるダイアログ**が出ます。次で説明します。

## 許可ダイアログの読み方

Claude Code は、ファイルを書き換えたりコマンドを実行したりする前に、**あなたに確認を取ります。**

<!-- TODO(画像): 許可ダイアログ。docs/assets/img/permission-dialog.png -->

表示されるのは概ね次の3択です。

| 選択肢 | 意味 | 使いどころ |
|---|---|---|
| はい（1回だけ） | 今回だけ許可 | **基本はこれ。** 内容を見てから判断 |
| はい（今後も許可） | 同種の操作を以後確認しない | 安全だと確信できる操作だけ |
| いいえ | 実行しない | 意図と違うことをしようとしている |

**慣れるまでは「1回だけ」を選び、何をしようとしているか毎回読んでください。** 「今後も許可」を安易に選ぶと、意図しない変更に気づけなくなります。

削除やフォルダの一括操作を求められたときは、特に内容をよく読んでください。

## 知っておくと便利なコマンド

入力欄で `/` から始まる特別なコマンドが使えます。よく使うのは次の3つです。

| コマンド | 何をするか |
|---|---|
| `/help` | 使えるコマンドの一覧を表示 |
| `/clear` | それまでの会話を忘れさせて仕切り直す |
| `/init` | フォルダの内容を調べて `CLAUDE.md` を作る（次項） |

終了するときは `/exit`、または `Ctrl + C` を2回押します。

## CLAUDE.md：毎回説明する手間をなくす

作業フォルダに **`CLAUDE.md`** というファイルを置いておくと、Claude Code は起動のたびにそれを読みます。毎回説明していることをここに書いておけば、以後は省略できます。

```markdown
# このフォルダについて

営業部の月次報告書を管理しているフォルダです。

## お願いしたいこと
- 日付の表記は「2026年8月20日」の形式に統一してください
- 金額は必ず3桁区切りで書いてください
- `archive/` フォルダの中身は変更しないでください
```

`/init` を実行すると、Claude 自身がフォルダを調べてたたき台を作ってくれます。それを手で直すのが早道です。

## 任せてよい作業・避けるべき作業

**向いている作業**

- 複数ファイルにまたがる調査・一覧化
- 表記ゆれの統一、一括置換
- 定型フォーマットへの変換
- 「このフォルダで何が起きているか」の把握
- （プログラムを扱う人なら）エラーの原因調査と修正

**避けたほうがよい作業**

- バックアップのない大事なファイルの一括変更
- 本番環境への反映や公開作業
- 認証情報やパスワードを含むフォルダでの作業
- 内容を確認せずに結果をそのまま使うこと

## つまずいたときの合言葉

**「まず説明させる」** です。

```text
何をしようとしているか、実行する前に手順を説明してください。
```

いきなりやらせず一度説明させると、意図がずれていればその場で気づけます。長い作業ほど効果があります。
