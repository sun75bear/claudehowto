# はじめての Claude

このサイトは、**AI をまだ使ったことがない・使ってみたけどピンとこなかった人**に向けて、Claude（クロード）の契約から実際の仕事での使い方までをひと通り案内するものです。

パソコンで文書を作ったりメールを書いたりできる方なら、そのまま読み進められる内容にしてあります。プログラミングの知識は前提にしていません。

上から順に読めば、無理なく使えるようになるよう並べてあります。
