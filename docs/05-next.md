# 5. この先は自分で

2つ動かせたなら、もう使えています。**ここから先は、自分の目的に合わせて調べたほうが速いです。**

Claude Code は更新が非常に速く、情報も豊富です。網羅的な解説を読むより、**やりたいことが出てきたときにその都度調べる**ほうが身につきます。

## まずは動画を見るのが早い

YouTube で **「Claude Code 使い方」「Claude Code 入門」** などと検索すると、実演動画が多数見つかります。

**動いている様子を見るのが、文章を読むより手っ取り早い**です。特に「自分の仕事に使えるか」を判断したい段階では、他の人がどう使っているかを眺めるのが一番参考になります。

## こんなこともできます

説明はしません。**そういうものがある**とだけ知っておいて、必要になったら調べてください。

- **スキル** — 繰り返す作業を手順として登録し、`/` から呼び出す
- **並列セッション** — 複数の作業を同時に走らせる
- **スケジュール実行** — 毎週・毎朝の作業を自動で回す
- **MCP / コネクタ** — Google Drive、Slack、GitHub など手元のフォルダ以外につなぐ
- **開発向けの使い方** — バグ修正、テスト作成、コミットと Pull Request の作成

## 用語のメモ

**権限モード**
: Claude Code がどこまで自分の判断で実行してよいかの設定。Plan / Auto / Manual / Accept edits。

**差分（diff）**
: 変更前と変更後の違いを表示したもの。緑が追加、赤が削除。

**`CLAUDE.md`**
: 作業フォルダに置くと毎回読んでもらえる指示書。

**セッション**
: 1つの作業のまとまり。複数を同時に開ける。

**MCP**
: Claude Code を外部のサービスやデータにつなぐ仕組み。

**ハルシネーション**
: AI が事実でないことをもっともらしく答えてしまう現象。数字と固有名詞は必ず確認を。
