# 2. 契約する

!!! abstract "このページでできるようになること"
    アカウントを作り、無料で使い始められます。あわせて、有料プラン（Pro）に上げるべきタイミングと、やめ方も分かります。

## 結論を先に

1. **まず無料（Free）で始めてください。** 支払い情報の登録は不要です。
2. 1週間ほど使って「もっと使いたい」「上限に当たる」と感じたら **Pro（月 $20）** に上げてください。
3. [Claude Code](07-claude-code.md) を使いたい場合は **Pro が必須**です。無料プランでは使えません。

## 手順1: アカウントを作る

1. ブラウザで **[claude.ai](https://claude.ai)** を開きます
2. 「Sign up」を選びます
3. Google アカウントでログインするか、メールアドレスを入力します
4. メールに届いた確認コードを入力します
5. 名前などを入力すると、すぐにチャット画面が開きます

これで無料プランの利用が始まっています。**この時点では料金は一切かかりません。**

!!! tip "日本語で使えます"
    画面の一部は英語ですが、日本語で話しかければ日本語で返ってきます。表示自体を日本語にしたい場合は、設定（Settings）から言語を変更できます。

## 手順2: 無料のまま1週間ほど使う

いきなり課金する必要はありません。無料プランでも、Claude がどんなものかを判断するには十分に使えます。

無料プランで試すのに向いているのは [実例集](04-examples.md) の前半（要約・文章作成・翻訳）です。まずはそこから触ってみてください。

## 手順3: Pro に上げるか判断する

無料プランには**一定時間あたりに使える量の上限**があります。上限に達すると「しばらく待ってください」と表示され、数時間後にまた使えるようになります。

これが週に何度も起きるようなら、Pro に上げる時期です。

### Free と Pro の違い

判断に必要な3点だけに絞ります。

| | **Free** | **Pro** |
|---|---|---|
| 料金 | $0 | **月払い $20 / 年払い $17（月あたり）** |
| 使える量 | 上限あり。当たると数時間待つ | Free より大幅に多い |
| **[Claude Code](07-claude-code.md)** | **使えない** | **使える** |
| プロジェクト機能など | 制限あり | 利用可 |

!!! note "2026年8月時点の料金です"
    金額と提供内容は変わることがあります。最新は公式の [料金ページ](https://claude.com/pricing) で確認してください。表示は米ドルで、請求時に円換算されます。

!!! info "さらに上のプランもあります"
    たくさん使う個人向けの Max、会社で複数人が使うための Team・Enterprise もあります。このサイトでは扱いません。必要になったら [料金ページ](https://claude.com/pricing) をご覧ください。

### Pro への上げ方

1. 画面左下（または右上）の自分の名前・アイコンをクリック
2. **Settings** → **Billing**（または画面内の「Upgrade」ボタン）を選ぶ
3. Pro を選び、クレジットカード情報を入力する
4. 決済が完了すると、その場で Pro になります

**月払いと年払い**があります。まずは月払いで始め、続きそうなら年払いに変えるのが無難です。年払いのほうが割安ですが、1年分をまとめて支払います。

## やめ方（解約）

いつでも解約できます。

1. **Settings** → **Billing** を開く
2. 「Cancel subscription」を選ぶ

解約しても**支払い済みの期間が終わるまでは Pro のまま使えます**。期間が終わると自動的に無料プランに戻り、それ以降は請求されません。アカウントや過去の会話は残ります。

!!! warning "自動更新に注意"
    有料プランは解約しない限り自動で更新されます。「試しに1か月だけ」のつもりなら、使い終わった時点で解約手続きをしておくと安心です。解約してもその月は使えます。

## よくある詰まりどころ

| 症状 | 対処 |
|---|---|
| 確認メールが届かない | 迷惑メールフォルダを確認。数分待っても来なければ再送する |
| 「上限に達しました」と出た | 無料プランの制限。数時間待つか、Pro に上げる |
| カードが通らない | 海外決済がブロックされている場合があります。カード会社に確認するか別のカードで試す |
| 英語の画面で戸惑う | 日本語で話しかければ日本語で返ります。Settings から表示言語も変更可 |
