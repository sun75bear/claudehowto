# 10. FAQ・トラブル対応

## 契約・使用量

??? question "Code タブを押したら「アップグレード」と言われる"
    無料プランのままです。Claude Code は Pro 以上でのみ使えます。[2. Pro を契約する](02-pro-plan.md) を参照してください。

??? question "急に「上限に達しました」と止まった"
    5時間ごとのセッション上限か、週の上限に達しています。**Settings → Usage** で残量と次のリセット時刻が確認できます。待つか、使用量クレジット（従量課金）で続けるか、上位プランを検討してください。詳しくは [2章の使用量の節](02-pro-plan.md#usage-limits)。

??? question "チャットしか使っていないのに上限が減っている"
    チャットと Claude Code の使用量は**合算**されます。別枠ではありません。

??? question "解約したのに使えるままだが、請求は止まっているか"
    支払い済みの期間が終わるまでは Pro のまま使えます。期間終了後に自動的に無料プランへ戻り、それ以降の請求はありません。Settings → Billing で次回請求日を確認できます。

## インストール・起動

??? question "Windows でフォルダを選んでも動かない"
    **Git for Windows が入っていない**可能性が高いです。ローカルのフォルダを扱うには必要です。[git-scm.com](https://git-scm.com/downloads/win) から入れてください。インストーラーの選択肢は既定のままで構いません。

??? question "サインインできない / 403 エラーが出る"
    いったんサインアウトして、ブラウザで [claude.ai](https://claude.ai) にログインし直してから、アプリを再起動してください。それでも直らない場合は [公式のトラブルシュート](https://code.claude.com/docs/en/desktop#troubleshooting) を参照してください。

??? question "ターミナル版で `claude` は認識されませんと出る"
    1. ターミナル（PowerShell）を**いったん閉じて開き直す**
    2. `claude doctor` を実行して診断結果を見る
    3. 直らなければ再インストール

    詳しくは [公式のトラブルシュート](https://code.claude.com/docs/en/troubleshoot-install)。

??? question "ターミナルが苦手で進められない"
    デスクトップアプリを使ってください。ターミナルなしで同じことができます。[3. インストールする](03-setup.md)。

## 使っていて困ること

??? question "意図しないファイルを書き換えられた"
    権限モードが Manual 以外になっている可能性が高いです。送信ボタンの隣の選択肢を確認してください。慣れるまでは **Manual** で、差分を読んでから承認してください。バックアップか Git があれば元に戻せます。

??? question "とんでもない方向に進み始めた"
    **停止ボタンを押してください。** 止めずに追加の指示を送って軌道修正することもできます。最後まで待つ必要はありません。

??? question "大きな作業を任せるのが怖い"
    権限モードを **Plan** にして、方針だけ出させてください。ファイルには一切触りません。合意できてから Manual に戻して実行させます。

??? question "毎回同じ説明をするのが面倒"
    作業フォルダに `CLAUDE.md` を置いてください。`/init` でたたき台が作れます。[7. 使いこなす](07-power-up.md)。

??? question "途中から話が噛み合わなくなった"
    抱えている情報が増えすぎています。`/clear` で仕切り直してください。前提は `CLAUDE.md` に書いてあれば説明し直す必要はありません。

??? question "集計の数字が信用できない"
    「暗算せずに、スクリプトを書いて実行してください」と頼んでください。計算をコンピュータにやらせれば結果は信頼できます。[5章の例4](05-examples.md)。

??? question "書いていないことを勝手に付け足される"
    「渡した資料にないことは書かないでください」と明示してください。要約や一覧化では特に有効です。

??? question "一括で実行されるのが不安"
    指示文の最後に **「まず1つだけやって見せてください。それでよければ残りを進めてください」** と付けてください。これだけで事故がかなり防げます。

??? question "答えが本当か不安"
    そのまま次のように聞いてください。

    ```text
    今の作業のうち、事実確認が必要な箇所と、あなたの推測が入っている箇所を分けて教えてください。
    ```
