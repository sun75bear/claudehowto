# 5. うまく使うコツ

!!! abstract "このページでできるようになること"
    「思ったのと違う答えが返ってくる」を減らします。原因のほとんどは指示の書き方です。

## 指示の型：4つを書く

うまくいかない指示は、たいてい情報が足りていません。次の4つを意識するだけで結果が変わります。

| | 何を書くか | 例 |
|---|---|---|
| **目的** | 何のために使うか | 「上司への報告に使います」 |
| **材料** | 判断のもとになる情報 | 資料の添付、前提の説明 |
| **出力形式** | どんな形で欲しいか | 「箇条書きで5つ」「400字」「表で」 |
| **制約** | やってほしくないこと | 「専門用語は使わない」「推測で補わない」 |

### 悪い例と良い例

**悪い例**

```text
この資料をまとめて
```

**良い例**

```text
この資料を、明日の部内会議で口頭共有するためにまとめてください。（目的）
出力は、結論1行＋要点3つの箇条書きでお願いします。（形式）
参加者は他部署の人が中心なので、専門用語は避けてください。（制約）
```

材料（資料）は添付済み。この差だけで、手直しの量が大きく減ります。

## 「役割」を与えると精度が上がる

冒頭に立場を指定すると、答えの視点が変わります。

```text
あなたは経験10年の総務担当者です。その立場から、以下の規程案の問題点を指摘してください。
```

万能ではありませんが、**専門的な観点で見てほしいとき**に有効です。

## 一度で終わらせない

一発で完璧な答えを狙うより、**2〜3往復で詰める**ほうが速くて確実です。

```text
1回目: 「〜をまとめて」
2回目: 「3つ目をもっと具体的に」
3回目: 「全体を300字に収めて」
```

Claude は直前までの会話を覚えているので、短い追加指示で通じます。

## うまくいかないときの立て直し方

| 症状 | 対処 |
|---|---|
| 一般論しか返ってこない | 材料が足りない。資料を添付するか、前提を具体的に書く |
| 話が長すぎる | 「200字で」「箇条書き5つまで」と量を指定する |
| 勝手に内容を足してくる | 「渡した情報にないことは書かないでください」と明示する |
| 褒めるばかりで役に立たない | 「賛成意見は不要です。問題点だけ挙げてください」 |
| だんだんおかしくなってきた | 会話が長くなりすぎ。**新しい会話**を開いて、必要な材料を貼り直す |
| 日本語が不自然 | 「自然な日本語のビジネス文書として書き直して」と頼む |

## 間違いへの備え方

Claude は**もっともらしく間違える**ことがあります。使いこなしている人ほど、この前提で組み立てています。

**確認が必須のもの**

- 数字（金額、割合、集計結果）
- 制度・法律・規約の内容
- 固有名詞、日付、出典

**確認が要らないもの**

- 文章の言い回し、構成
- アイデア出し、たたき台
- 自分がすでに知っていることの整理

**使える一手** — 答えの後にこう聞くと、危ない箇所が見えます。

```text
今の回答のうち、事実確認が必要な箇所と、あなたの推測が入っている箇所を分けて教えてください。
```

## やってはいけない使い方

- **内容を確認せずにそのまま提出する** — 責任は使った人にあります
- **判断そのものを任せる** — 材料を出させて、決めるのは自分
- **同じ会話で無関係な話題を続ける** — 精度が落ちます

## まとめ

- **目的・材料・形式・制約**の4つを書く
- 一発を狙わず、**会話で詰める**
- 数字と制度は**必ず裏を取る**
