# 2. Pro を契約する

!!! abstract "このページでできるようになること"
    Pro プランを契約して Claude Code を使える状態にします。あわせて、**使用量の上限**という仕組みを先に理解しておきます。これを知らないと必ず驚きます。

## 無料では使えません

はっきり書いておきます。

!!! danger "Claude Code は有料プラン専用です"
    **無料（Free）プランでは Claude Code は使えません。Pro（月 $20）以上の契約が必要です。**

無料プランでできるのはチャットだけです。チャットの使い勝手を確かめるために無料で触ってみるのは構いませんが、**このサイトの主題である Claude Code には到達しません。**

## 契約する

1. ブラウザで **[claude.ai](https://claude.ai)** を開きます
2. アカウントがなければ「Sign up」から作ります（Google アカウントまたはメールアドレス）
3. 画面内の **Upgrade**、または自分のアイコン → **Settings** → **Billing** を開きます
4. **Pro** を選び、クレジットカード情報を入力します
5. 決済が完了すると、その場で Pro になります

**料金（2026年8月時点）**

| | 月払い | 年払い |
|---|---|---|
| **Pro** | **$20 / 月** | $17 / 月相当（1年分を一括） |

まずは月払いで始め、続きそうなら年払いに変えるのが無難です。

!!! note "金額は変わることがあります"
    最新は公式の [料金ページ](https://claude.com/pricing) で確認してください。表示は米ドルで、請求時に円換算されます。海外決済がブロックされているカードだと通らないことがあります。

## 使用量の上限を先に理解する { #usage-limits }

**ここが本題です。** Claude Code はチャットに比べて消費が大きいので、上限の仕組みを知らないまま使うと「急に止まった」と面食らいます。

### 2段構えになっています

| | 内容 |
|---|---|
| **5時間ごとのセッション上限** | 使い始めてから5時間が1区切り。区切りごとにリセットされます |
| **週ごとの上限** | それとは別に、1週間単位の枠があります。リセット時刻はアカウントごとに固定 |

さらに重要な点として、**チャットと Claude Code の使用量は合算**されます。別枠ではありません。

### 残量の見方

**Settings → Usage** に進捗バーがあり、次のことが分かります。

- 5時間セッションの消費量と、**次のリセットまでの残り時間**
- 週の枠の消費量

<!-- TODO(画像): Settings → Usage の進捗バー。docs/assets/img/settings-usage.png -->

大きな作業を始める前にここを見る癖をつけると、途中で止まって困ることが減ります。

### 上限に達したら

3つの選択肢があります。

1. **リセットを待つ** — 5時間の区切り、または週の区切りまで待てば戻ります
2. **使用量クレジットを使う** — 上限を超えた分を従量課金で買い足し、そのまま作業を続けられます
3. **上位プランに上げる**（次項）

!!! note "2026年8月時点の仕組みです"
    詳細は公式ヘルプの [使用量と上限について](https://support.claude.com/en/articles/11647753-how-do-usage-and-length-limits-work) を確認してください。

## 上位プラン（Max）について

Pro の枠を大きく増やした **Max** というプランがあります。Pro の 5倍・20倍の枠を持つ2種類が用意されています。

判断はシンプルです。

> **5時間ごとの上限や週の上限に、頻繁にぶつかるようになったら検討する。**

そこまで使い込んでいる時点で、自分にとって必要かどうかは判断がつくはずです。それまでは Pro で十分です。詳細は [料金ページ](https://claude.com/pricing) をご覧ください。

会社で複数人が使う場合は Team / Enterprise という選択肢もありますが、このサイトでは扱いません。

## やめ方（解約）

1. **Settings** → **Billing** を開く
2. 「Cancel subscription」を選ぶ

支払い済みの期間が終わるまでは Pro のまま使えます。期間終了後に自動的に無料プランへ戻り、それ以降は請求されません。アカウントや過去の会話は残ります。

!!! warning "自動更新に注意"
    解約しない限り自動で更新されます。「試しに1か月だけ」のつもりなら、使い終わった時点で解約手続きをしておいてください。解約してもその期間は使えます。
