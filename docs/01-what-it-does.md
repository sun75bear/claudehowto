# 1. 何ができるか

## チャット型 AI の天井

「ファイルを添付 → 頼む → 返事をコピー → 元のファイルに貼る → 次のファイルへ」。この流れに覚えがあるはずです。

ファイルが3つならまだ我慢できます。**30個あったらどうでしょうか。**

この「**1往復につき1ファイル、反映は手作業**」という構造が天井です。しかもこの天井は ChatGPT でも Gemini でも Claude のチャットでも同じで、**どこの会社のものを使っても変わりません。**

## 何が変わるか

半年分の議事録から「やると言ったまま終わっていないこと」を洗い出す、という作業で比べます。

=== "チャットでやると"

    ```mermaid
    sequenceDiagram
        actor You as あなた
        participant Chat as チャット
        loop 議事録の数だけ（30回）
            You->>Chat: 1つ開いてコピーして貼る
            Chat-->>You: 抜き出した結果
            You->>You: メモ帳に貼って保存
        end
        You->>You: 30個分を突き合わせて整理
    ```

    **1〜2時間。しかも途中で飽きる。**

=== "Claude Code だと"

    ```mermaid
    sequenceDiagram
        actor You as あなた
        participant CC as Claude Code
        You->>CC: フォルダと条件を1回伝える
        CC->>CC: 30個を探して読む
        CC->>CC: 突き合わせて重複を除く
        CC-->>You: 一覧表
    ```

    **数分。** 読むのも突き合わせるのも Claude Code の仕事になります。

差は「速い」ではなく **「やる気になるかどうか」** です。1〜2時間かかる作業は後回しにされ、永遠に着手されません。

## やってくれること

渡すのはファイルではなく**フォルダ**です。その中で Claude Code は、**探す**（何があるか調べる）・**読む**・**書く**（コピペは発生しない）・**実行する**（スクリプトを動かして結果を確認する）・**直す**（おかしければ自分で気づく）を自分で行います。

つまり、**あなたが手を動かしていた部分を引き取ります。**

効くのは「**複数のファイルにまたがる、手数の多い作業**」です。もともとはプログラマー向けの道具ですが、資料の整理・集計・一括変換にもそのまま使えます。コードを書けなくても構いません。

!!! tip "チャットとの使い分け"
    **ファイルを触らせるなら Claude Code、触らせないなら普通のチャット。** 相談・調べもの・文章の推敲はチャットのほうが手軽です。デスクトップアプリには両方のタブがあるので、行き来しながら使えます。

## 使い方は覚えなくていい

Claude Code は**日本語で話しかけるだけ**の道具です。コマンドを暗記する必要はありません。
