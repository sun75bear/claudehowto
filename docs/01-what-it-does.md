# 1. 何ができるか

## チャットの天井

「ファイルを添付 → 頼む → 返事をコピー → 元のファイルに貼る → 次のファイルへ」。ファイルが3つならまだ我慢できます。**30個あったらどうでしょうか。**

この「**1往復につき1ファイル、反映は手作業**」という構造が天井です。しかもこの天井は ChatGPT でも Gemini でも Claude のチャットでも同じです。

## 何が変わるか

半年分の議事録から「やると言ったまま終わっていないこと」を洗い出す、という作業で比べます。

=== "チャットでやると"

    ```mermaid
    sequenceDiagram
        actor You as あなた
        participant Chat as チャット
        loop 議事録の数だけ（30回）
            You->>Chat: 1つ開いてコピーして貼る
            Chat-->>You: 抜き出した結果
            You->>You: メモ帳に貼って保存
        end
        You->>You: 30個分を突き合わせて整理
    ```

    **1〜2時間。しかも途中で飽きる。**

=== "Claude Code だと"

    ```mermaid
    sequenceDiagram
        actor You as あなた
        participant CC as Claude Code
        You->>CC: フォルダと条件を1回伝える
        CC->>CC: 30個を探して読む
        CC->>CC: 突き合わせて重複を除く
        CC-->>You: 一覧表
    ```

    **数分。** 読むのも突き合わせるのも Claude Code の仕事になります。

## 何をしてくれるか

渡すのはファイルではなく**フォルダ**です。その中で Claude Code は、**探す・読む・書く・実行する・直す**を自分で行います。つまり、**あなたが手を動かしていた部分を引き取ります。**

効くのは「**複数のファイルにまたがる、手数の多い作業**」です。もともとはプログラマー向けの道具ですが、資料の整理・集計・一括変換にもそのまま使えます。コードを書けなくても構いません。逆に、相談や文章の推敲など**ファイルを触らせない用件は普通のチャットのほうが手軽**です。

操作は**日本語で話しかけるだけ**で、コマンドの暗記は要りません。このサイトでも操作方法の解説はしません。[3. 最初に動かす](03-first-run.md) で1本動かせば、あとは必要になったときに調べれば足ります。
