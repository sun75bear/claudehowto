# 3. Claude.ai の基本

!!! abstract "このページでできるようになること"
    画面のどこに何があるかを把握し、会話・ファイル添付・成果物の受け取りができるようになります。

## どこで使うか

3つの入口があります。中身は同じで、同じアカウントの会話がどれでも見られます。

| | 使い方 | 向いている場面 |
|---|---|---|
| **ブラウザ版** | [claude.ai](https://claude.ai) を開くだけ | まずはこれ。インストール不要 |
| **デスクトップアプリ** | [claude.com/download](https://claude.com/download) から入手 | 毎日使うなら。起動が速い |
| **モバイルアプリ** | App Store / Google Play | 移動中の下書き、写真を撮って質問 |

迷ったらブラウザ版で始めてください。

## 画面の基本

<!-- TODO(画像): チャット画面全体。docs/assets/img/chat-screen.png -->

- **中央の入力欄** — ここに書いて送ります。`Enter` で送信、`Shift + Enter` で改行
- **左のサイドバー** — 過去の会話の一覧。クリックすると続きから再開できます
- **「新しい会話」ボタン** — 話題が変わったらこれを押します（後述）

## 最初の一往復

入力欄に、たとえばこう書いて送ってみてください。

```text
あなたに何ができるのか、パソコンは使えるがAIは初めての人に向けて、
箇条書きで5つ、それぞれ1行で説明してください。
```

返事が返ってきます。気に入らなければ「もっと短く」「例を足して」と続けて言えば、その場で直してくれます。**一度で完璧を狙わず、会話で詰めていく**のが基本の使い方です。

## 会話は話題ごとに分ける

Claude は**同じ会話の中の、それまでのやりとりを覚えています**。だから続けて「もっと短く」が通じます。

逆に言うと、まったく別の話題を同じ会話で始めると、前の話に引きずられて精度が落ちます。**話題が変わったら「新しい会話」を押す** —— これだけで結果がかなり変わります。

## ファイルを渡す

ここからが本番です。入力欄のクリップのアイコンから、または**ファイルをドラッグ＆ドロップ**して渡せます。

渡せるもの:

- PDF、Word、Excel、PowerPoint
- テキストファイル、CSV
- 画像（スクリーンショット、写真、手書きメモの撮影も可）

<!-- TODO(画像): ファイル添付の様子。docs/assets/img/attach-file.png -->

たとえば会議資料の PDF を渡して「この資料の要点を5行で」と頼めば、それだけで仕事になります。**Claude は渡した資料を読んで答えられる**、ここが一番実用的な部分です。

!!! warning "何を渡してよいかは要注意"
    社外秘の資料や個人情報を含むファイルを渡してよいかは、所属先のルール次第です。[6. 気をつけること](06-cautions.md) を必ず読んでください。

## Artifacts（成果物を別枠で受け取る）

長い文章や表、資料の下書きを頼むと、**チャットの右側に別ウィンドウが開いて**そこに成果物が表示されることがあります。これが Artifacts です。

- 会話に埋もれず、**編集・コピー・ダウンロード**がしやすい
- 「3行目をこう直して」と頼むと、その場で書き換わる

長めの成果物を作らせるときに自然と出てくるので、覚えておく程度で構いません。

## Projects（同じ資料を何度も使う）

同じ資料を前提にした作業を繰り返すなら、**プロジェクト**にまとめられます。

たとえば「就業規則」「商品カタログ」をプロジェクトに入れておくと、そのプロジェクト内の会話ではいちいち添付しなくても Claude がその資料を参照します。

- 毎回同じ添付をしている、と気づいたらプロジェクト化のタイミングです
- 「うちの部署のルール」「この案件」といった単位で作ると分かりやすい

## Web 検索

最新の情報が必要なときは、「調べて」「最新の情報を検索して」と頼めば Web を検索して答えます。ただし**検索結果の解釈を間違えることもある**ので、重要な数字は元のページを開いて確認してください。

## 履歴の扱い

会話は自動的に保存され、左のサイドバーからいつでも見返せます。不要な会話は個別に削除できます。設定画面からは、会話の保存やデータの取り扱いに関する項目も変更できます（[6. 気をつけること](06-cautions.md) で扱います）。

## まとめ

- 話題が変わったら**新しい会話**
- **ファイルを渡す**と一気に実用的になる
- 一度で完璧を狙わず、**会話で詰める**
