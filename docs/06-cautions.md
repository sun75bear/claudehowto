# 6. 気をつけること

!!! abstract "このページでできるようになること"
    仕事で使うときに事故を起こさないための線引きが分かります。**このページだけは飛ばさないでください。**

## 大前提：入力した内容は社外に送られている

Claude はあなたのパソコンの中で動いているのではなく、**インターネット越しに Anthropic のサーバへ送られて処理されます。**

つまり、Claude に貼り付けた文章やファイルは、**社外のサービスにアップロードした**のと同じことです。この一点さえ押さえておけば、判断の大部分はつきます。

## 入れてはいけないもの

会社の情報を扱う場合、まずは**所属先のルールを確認**してください。ルールがない場合でも、次のものは避けるのが無難です。

- **個人情報** — 氏名・住所・電話番号・メールアドレス・マイナンバー・健康や病歴に関する情報
- **顧客から預かったデータ** — 契約上、社外に出せないことがほとんどです
- **未公開の経営情報** — 決算数値、人事情報、M&A や新製品の情報
- **認証情報** — パスワード、APIキー、社内システムのログイン情報
- **他社の秘密情報** — 秘密保持契約を結んで受け取った資料

### 判断に迷ったときの目安

> **「このファイルを、社外の取引先にメールで送れるか？」**

送れないものは、Claude にも入れない。この基準で考えると分かりやすくなります。

## 入れても比較的問題が少ないもの

- 公開済みの資料、プレスリリース、Webサイトの文章
- 自分で書いた文章の下書き（固有名詞を伏せたもの）
- 一般的な調べもの、業務知識の確認
- 固有名詞を「A社」「担当者B」などに置き換えた文章

!!! tip "伏せ字にして渡す"
    「取引先の名前だけ伏せれば渡せる」という場面は多いです。`〈A社〉` のように置き換えて相談し、返ってきた文章を自分で元に戻せば、実務上ほとんど困りません。

## 設定を確認しておく

Claude.ai の **Settings（設定）→ Privacy** のあたりに、自分のデータの扱いに関する項目があります。会話の内容をサービス改善に利用するかどうかの設定が含まれることがあるので、業務で使う前に一度目を通して、必要ならオフにしてください。

!!! note "会社契約の場合は扱いが異なります"
    会社が Team / Enterprise プランで契約している場合、データの取り扱いは個人プランと条件が違います。管理者に確認してください。

## 出した結果の責任は使った人にある

これは制度の話ではなく、実務の話です。

- Claude が書いた文章をそのまま送って内容が間違っていた場合、**責められるのはあなた**です
- 「AI がそう言った」は通用しません
- **必ず自分で読んでから出す。** 特に数字・日付・固有名詞

## 著作権まわり

- 他人の著作物を丸ごと貼って「これを書き直して」と頼み、それを自分の成果物として公開するのは避けてください
- Claude が生成した文章が、既存の文章と偶然似ることもあります。公開物に使うなら一度検索して確認すると安全です

## 社内で使うときの現実的な進め方

1. まず**公開情報だけ**で使ってみて、有用性を確かめる
2. 情報システム部門・法務に、業務利用の可否とルールを確認する
3. 「入れてよい情報」の線引きをチームで文章にしておく
4. その範囲内で本格的に使い始める

3 が抜けたまま広がるのが一番危ないので、**書いて共有する**ことをおすすめします。

## まとめ

- 入力内容は**社外に送られている**
- 判断基準は「**取引先にメールで送れるか**」
- **出した結果の責任は自分にある**

ここまでで、日常的に使うぶんには十分です。お疲れさまでした。
