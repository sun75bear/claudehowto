# 7. 使いこなす

!!! abstract "このページでできるようになること"
    毎回の説明を省き、複数の作業を同時に走らせ、定期作業を自動化できるようになります。

## 指示の書き方：4つを書く

うまくいかない指示は、たいてい情報が足りていません。

| | 何を書くか | 例 |
|---|---|---|
| **目的** | 何のためか | 「取引先に提出する資料です」 |
| **材料** | どこを見ればよいか | 「`@template.md` を見本にしてください」 |
| **形式** | どんな形で欲しいか | 「表で」「`summary.md` に保存して」 |
| **制約** | やってほしくないこと | 「元ファイルは変更しないで」「推測で補わないで」 |

Claude Code では特に**制約**が効きます。「まず1つだけ」「実行前に確認して」の一文があるかどうかで、事故の起きやすさが変わります。

## 大きな作業は Plan モードから

いきなり実行させず、方針を先に出させる習慣をつけてください。

1. 権限モードを **Plan** に切り替える
2. やりたいことを伝える
3. 出てきた方針を読み、ずれていれば指摘する
4. 合意できたら **Manual** に戻して実行させる

長い作業ほど効きます。やり直しの時間が丸ごと消えます。

## `CLAUDE.md`：毎回の説明をやめる

作業フォルダに **`CLAUDE.md`** というファイルを置いておくと、Claude Code は毎回それを読んでから作業を始めます。

```markdown
# このフォルダについて

営業部の月次報告書を管理しています。

## お願いしたいこと
- 日付の表記は「2026年8月20日」の形式に統一してください
- 金額は3桁区切りで書いてください
- 社外の方の名前には「様」を付けてください

## 触らないでほしいもの
- `archive/` フォルダの中身は変更しないでください
- `原本/` は読むだけにしてください
```

**同じ注意を2回書いたら、`CLAUDE.md` に移すサイン**です。

`/init` と入力すると、Claude がフォルダの中身を調べてたたき台を作ってくれます。それを手で直すのが早道です。

!!! tip "作業しながら覚えていきます"
    Claude Code は作業の中で得た知識（どのコマンドで動くか、何が落とし穴か）を自分でも記録していきます。使うほど説明が少なくて済むようになります。

## スラッシュコマンドとスキル

入力欄で `/` を打つ（または `+` ボタン）と、使えるコマンドの一覧が出ます。

<!-- TODO(画像): スラッシュコマンドの一覧。docs/assets/img/slash-commands.png -->

| コマンド | 何をするか |
|---|---|
| `/help` | 使えるコマンドの一覧 |
| `/clear` | 会話をリセットして仕切り直す |
| `/init` | `CLAUDE.md` のたたき台を作る |

**繰り返す作業は「スキル」として登録**できます。毎月やる棚卸しや、決まったチェック項目があるなら、手順を書いたスキルを作っておけば `/` から呼び出すだけになります。チームで共有することもできます。

## 会話が長くなったら `/clear`

作業が進むと、Claude が抱えている情報が増えていきます。増えすぎると精度が落ちます。

**話題が変わったら `/clear`。** これだけで結果が安定します。必要な前提は `CLAUDE.md` に書いてあるので、リセットしても説明し直す必要はありません。

## 並列セッション：同時に走らせる

サイドバーから**複数のセッションを同時に開ける**ようになっています。

<!-- TODO(画像): 並列セッション。docs/assets/img/parallel-sessions.png -->

- それぞれが独立した文脈を持つので、混ざりません
- 片方に長い作業をさせている間に、もう片方で別の相談ができます
- 本筋を止めたくない小さな質問には、**サイドチャット**も使えます

## 定期作業を自動化する

毎週・毎朝やる作業は、**スケジュール実行**に載せられます。

- **デスクトップのスケジュールタスク** — 自分のパソコン上で動く。手元のファイルを直接扱える
- **クラウドで動くもの（ルーティン）** — パソコンを閉じていても動く

「毎週月曜に議事録フォルダを棚卸しして未完了を報告」といった作業が、放っておいても回るようになります。

## 外部ツールとつなぐ（MCP・コネクタ）

**MCP** という仕組みで、Claude Code を手元のファイル以外にもつなげられます。

- Google Drive の資料を読む
- Jira / Linear のチケットを更新する
- Slack の会話を参照する
- GitHub と連携する

設定の手順はここでは扱いませんが、**「手元のフォルダ以外にも広げられる」**ということだけ知っておいてください。詳しくは [MCP のクイックスタート](https://code.claude.com/docs/en/mcp-quickstart) を参照してください。

## 場所を移して続ける

セッションは1つの入口に固定されません。外出先ではモバイル、席に戻ったらデスクトップ、といった移動ができます。時間のかかる作業をクラウドに投げて、後で結果だけ確認するという使い方もできます。
